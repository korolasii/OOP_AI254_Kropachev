# ⚔️ Pixel Battle

**Практична робота: принципи ООП, інтерфейси, анонімні класи, лямбда-вирази**

⏱ Час виконання: **90 хвилин** · 🎯 Максимум: **5 балів** (+2 за спецзавдання)

Pixel Battle - покрокова битва в стилі старих RPG. Три герої б'ються проти трьох монстрів. Поки що кожен персонаж уміє лише одне - звичайну атаку. Ваше завдання - дати їм **вміння**, **пасивки** та **ультимейти**.

## ▶️ Як запустити

**IntelliJ IDEA** (рекомендовано):
1. Відкрийте папку проєкту, бо вона вже налаштована.
2. Якщо IDEA попросить JDK, виберіть **JDK 17 або новіший** (*File → Project Structure → Project → SDK*).
3. Угорі праворуч виберіть конфігурацію **Pixel Battle** і натисніть ▶.

**Термінал** (з кореня проєкту):

```bash
# Windows
javac -encoding UTF-8 -d out -sourcepath src src\pixelbattle\Main.java
java -cp "out;resources" pixelbattle.Main

# Linux / macOS
javac -encoding UTF-8 -d out -sourcepath src src/pixelbattle/Main.java
java -cp "out:resources" pixelbattle.Main
```

> Якщо замість персонажів рожеві квадрати, програма не знайшла картинки. Перевірте, що папка `resources` позначена як **Resources Root** (правий клік → *Mark Directory as*).

### Як грати
- **Клік по ворогу** - вибрати ціль (над нею червона стрілка).
- **Кнопки внизу** - вміння героя, чий зараз хід (над ним жовта стрілка).
- Число в дужках на кнопці - скільки ходів до кінця **перезарядки**.
- **Кнопка ★** - ультимейт. Вона активна, коли **енергія** (синя смужка під HP) заповнена. Енергія набирається за кожну дію (+25) і за кожен отриманий удар (+10).

В Огра вже є пасивка **«Товста шкіра»**: за один удар він втрачає не більше 25 HP. Це **приклад** того, як пишеться пасивка.

Гра вже працює: можна битися, є анімація, ефекти та журнал бою. Але без ваших доробок герої часто програють.

### Структура проєкту
```
src/pixelbattle/
├── Main.java              точка входу
├── core/                  «правила гри» (читайте, щоб знати, що є)
│   ├── Fighter.java         базовий клас бійця
│   ├── Hero.java            герой (ним керує гравець)
│   ├── Enemy.java           ворог (ним керує комп'ютер)
│   ├── Skill.java           вміння: назва, ціль, перезарядка, ефект
│   ├── SkillEffect.java     функціональний інтерфейс ефекту (для лямбд)
│   ├── Ultimate.java        інтерфейс ультимейту
│   └── Target.java          на кого діє вміння
├── heroes/                ✏️ Knight, Mage, Archer
├── enemies/               ✏️ Slime, Goblin, Ogre
├── ultimates/             ✏️ Meteor
└── engine/                рушій: ходи, графіка, ефекти (змінювати НЕ потрібно)
resources/sprites/         картинки
```

✏️ - тут ви пишете код. Усі місця позначені `TODO` з номером. В IntelliJ їх список відкривається через **View → Tool Windows → TODO**.

### Корисні методи (є в кожного бійця)
| Метод | Що робить |
|---|---|
| `getName()`, `getHp()`, `getMaxHp()`, `isAlive()` | інформація про бійця |
| `takeDamage(n)` | завдати `n` шкоди, повертає, скільки реально знято |
| `heal(n)` | вилікувати на `n`, повертає, скільки відновлено |
| `setGuarding(true)` | захист: до свого наступного ходу шкода вдвічі менша |
| `stun(n)` | оглушити на `n` ходів (оглушений пропускає хід) |
| `random(min, max)` | випадкове число від `min` до `max` включно |
| `chance(p)` | `true` з імовірністю `p` відсотків |
| `addSkill(skill)` | додати вміння (викликати в конструкторі) |
| `setUltimate(ult)` | задати ультимейт (викликати в конструкторі) |

> 💡 Вся графіка працює сама: кнопки, цифри шкоди, зірочки оглушення, смужка енергії, ефект ультимейту. Вам потрібно писати **лише логіку**.

## 📝 Що потрібно зробити

### Частина 1. Вміння (лямбда-вирази)

Вміння створюється в конструкторі персонажа. Ефект записується **лямбдою**:

```java
addSkill(new Skill("Назва", Target.ENEMY, перезарядка, (user, target) -> {
    int dmg = target.takeDamage(random(10, 15));
    return user.getName() + " б'є " + target.getName() + ": " + dmg + " шкоди";
}));
```

`Target.ENEMY` - по вибраному ворогу, `Target.ALLY` - по найбільш пораненому союзнику, `Target.SELF` - на себе. Готовий приклад є в `Knight.java` («Удар мечем»).

### Частина 2. Пасивки (перевизначення методів, поліморфізм)

У `Fighter` є два методи, які за замовчуванням нічого не роблять:

```java
protected void onTurnStart()                    // на початку кожного свого ходу
protected int modifyIncomingDamage(int damage)  // змінює шкоду, що надходить
```

Перевизначте їх (`@Override`) у потрібному класі. Приклад - пасивка в `Ogre.java`.

### Частина 3. Ультимейти (інтерфейс, анонімні класи)

Ультимейт - це інтерфейс з **трьома** методами, тому лямбдою його не записати:

```java
public interface Ultimate {
    String getName();
    String getDescription();
    String activate(Fighter user, Fighter[] allies, Fighter[] enemies);
}
```

`allies` і `enemies` - масиви. Перебирайте їх циклом `for` і не забувайте перевіряти `isAlive()`.
Шаблон анонімного класу:

```java
setUltimate(new Ultimate() {
    @Override public String getName() { return "..."; }
    @Override public String getDescription() { return "..."; }
    @Override public String activate(Fighter user, Fighter[] allies, Fighter[] enemies) {
        for (Fighter e : enemies) {
            if (e.isAlive()) { ... }
        }
        return "...";
    }
});
```
